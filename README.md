# 🌍 地層堆積シミュレーション (Geological Sedimentation Simulation)

Go言語（Golang）と2Dゲームエンジン **Ebitengine** を使用した、簡易的な地層の堆積（ストラティグラフィ）シミュレーションです。
<img width="799" height="644" alt="スクリーンショット 2026-05-23 060156" src="https://github.com/user-attachments/assets/a33d1cd6-2c94-4b8f-862f-b546c6afec5d" />

時間の経過とともに異なる物質（砂や泥）が上空から降り注ぎ、重力と安息角の物理法則に従って滑らかな斜面を作りながら、美しいボーダー状の地層（互層）を形成していく様子をリアルタイムに観察できます。

## 🛠️ 動作環境 / 依存関係

- **Go**: 1.18以上を推奨
- **Ebitengine (v2)**: 2Dゲームエンジン

## 🚀 実行方法

リポジトリをクローンするかダウンロードし、以下のコマンドを実行してください。

```bash
# 依存関係のダウンロード
go mod tidy

# シミュレーションの実行
go run main.go
🔬 シミュレーションの仕組み
堆積 (Sedimentation): 一定時間（フレーム）ごとに、砂（黄土色）と泥（茶色）のモードが切り替わり、ランダムなX座標から粒子が落下します。

崩落・侵食 (Erosion & Avalanche): セル・オートマトンのアルゴリズムを使用。粒子が積み上がり、斜面が物質固有の「安息角」を超えると、左右の低い方へと自動的に滑り落ちます。これにより、自然な地層の層理面が形成されます。
